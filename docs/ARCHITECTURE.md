# Архитектура

- `src/ZapretDesktop`: WPF (.NET 8), настройки, трей, интерфейс диагностики и обновлений.
- `src/ZapretService`: Windows-служба, запуск/остановка winws, подбор стратегий, восстановление и установка компонентов.
- `installer`: сценарий Inno Setup, подготовка проверенных компонентов, оформление мастера.
- `tests`: локальные тесты IPC, стратегий, обновления, восстановления и интерфейса.

## Подключение

UI → локальный named pipe → служба → winws.exe → WinDivert.

Стратегии импортируются с проверкой допустимых аргументов и файловых путей. Процесс движка принадлежит Job Object службы. Автоподбор сначала проверяет сохранённый кандидат, затем перебирает стратегии с проверками доступности. Смена сети учитывается при выборе сохранённого режима.

## Сетевые обращения

- `www.youtube.com`: диагностический HTTPS-запрос.
- `discord.com/api/v10/gateway`: диагностический запрос API.
- `1.1.1.1` / `1.0.0.1`: DNS-over-HTTPS Cloudflare при проблемах системного DNS в диагностике. Системный DNS и hosts не изменяются этой проверкой.
- GitHub API и серверы загрузки GitHub: проверка и загрузка компонентов Flowseal по запросу пользователя.
- `t.me/noirlie`: открывается в браузере только при нажатии ссылки автора.

Собственного сервера, учётной записи приложения и отправки телеметрии в исходном коде нет. У движка и его драйвера есть доступ к сетевым пакетам в рамках выбранной стратегии.

## Обновления

Архив проверяется по SHA-256 из метаданных GitHub, структуре, путям и допустимым стратегиям. Установка компонентов выполняется повышенным процессом в защищённой папке с резервной копией. При повторной установке создаются недостающие пользовательские списки; существующие списки сохраняются.

Это не полная атомарная транзакция всего приложения: подготовка службы и установка UI — разные этапы. При сбое сохраняются журналы и резервные копии; повторная установка может потребоваться.

## Границы проверки

Тесты не являются независимым аудитом безопасности. Доступность сайта не гарантирует все функции сервисов. Встроенного автообновления самого UI с этого репозитория пока нет.
